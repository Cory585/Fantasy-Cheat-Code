Draft Masterclass

Pick your draft slot to see every pick you'll make in a snake draft and who's likely on the board at each one.

Draft board

Likely available at your picks

Players ranked around each pick by average draft position (ADP). Everyone ranked ahead of a pick is assumed to be gone.

    Still to build

    • Suggestions that account for your roster so far, not just ADP.
    • Tiers, so you can see when a position is about to run dry.
    • Live draft tracking: mark picks as they happen and update what's left.
    • Mock drafts against opponents who pick by ADP.

    Data it uses

    ESPN average draft position from python -m app.data.collect, falling back to projections when there's no ADP. Your league size, draft slot, and number of rounds set the pick order.
